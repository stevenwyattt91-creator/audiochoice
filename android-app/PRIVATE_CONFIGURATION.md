# Private Android configuration

`local.properties` stays on the developer's machine and is excluded from Git.
Alongside the Android SDK entry generated by Android Studio, the AudioChoice
build reads:

```properties
audiochoice.apiBaseUrl=https://api.audiochoiceapp.com
audiochoice.googleServerClientId=YOUR-WEB-OAUTH-CLIENT-ID.apps.googleusercontent.com
```

`audiochoice.apiBaseUrl` is now optional. It defaults to the production API,
`https://api.audiochoiceapp.com`, set in `app/build.gradle.kts`. Override it only
to point a local build at a development server. Previously, omitting it compiled
`BuildConfig.API_BASE_URL` as an empty string and the app failed at its first
request with "AudioChoice staging has not been connected to this build yet",
which looked like a broken app rather than missing configuration.

That hostname is a domain we control on purpose. The API used to be published on
an `azurecontainerapps.io` address, and because the value is compiled into the
APK with no runtime override, no DNS change could move installed builds off it --
changing hosting meant shipping a new APK to every tester. A domain of our own
means the next hosting move needs no app release.

The Google value is the **Web application** OAuth client used by the backend, not
the Android OAuth client. The Android client is associated with
`com.audiochoice.mobile` and the signing certificate SHA-1 in Google Cloud.

## Beta signing

Beta builds also read the signing identity from here:

```properties
audiochoice.betaKeystoreFile=/absolute/path/to/beta.keystore
audiochoice.betaKeystorePassword=...
audiochoice.betaKeyAlias=...
audiochoice.betaKeyPassword=...
```

When those are absent the build falls back to debug signing. That is fine for a
local build and not fine for anything handed to a tester: the debug keystore is
generated per machine, so the signature changes between builds and testers hit
`INSTALL_FAILED_UPDATE_INCOMPATIBLE` on update. Recovering from that requires an
uninstall, which discards the device-local library mappings, playback positions
and reading positions that are not recoverable from the server.
