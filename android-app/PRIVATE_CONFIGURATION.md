# Private Android configuration

`local.properties` stays on the developer's Mac and is excluded from Git.
Alongside the Android SDK entry generated by Android Studio, the AudioChoice
staging build expects:

```properties
audiochoice.apiBaseUrl=https://YOUR-STAGING-API-HOST
audiochoice.googleServerClientId=YOUR-WEB-OAUTH-CLIENT-ID.apps.googleusercontent.com
```

The Google value is the **Web application** OAuth client used by the backend,
not the Android OAuth client. The Android client is associated with
`com.audiochoice.mobile` and the signing certificate SHA-1 in Google Cloud.
