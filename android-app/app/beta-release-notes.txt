The chapter you are on now shows in the player
- It sits between the cover and the scrub bar, the same place it has always been on iOS
- Books with no chapter marks in the file simply read "Audiobook", which is most loose MP3s
- A long chapter name is shortened with an ellipsis rather than wrapping, so it can never push the play button off the screen

An audiobook with no filters can now be scanned from the player
- The warning that filters are not active now carries a "Scan this audiobook" button
- Use it for a book that imported but shows no filter data. Two people importing the same book no longer have to wait for whoever scanned it first
- It is worded as a scan rather than a retry because for an edition nobody has scanned before, this is the first attempt

Signing up is shorter
- Email, password, confirm password, create. Nothing else is asked for
- No email verification step to get through before you can use the app

A short walkthrough on first sign-in
- Four steps covering importing a book, the transfer tool site, filters, and attaching an ebook to read
- It appears once. Everything it points at is reachable later from Profile

Please re-import nothing for this build. It changes what the player shows, not how books are read.
